# 📚 TIL (Today I Learned)

매일 배운 내용을 기록하는 저장소입니다.

## 📁 구조

| 폴더 | 내용 |
|---|---|
| `Python/`, `AI-ML/`, `Git/`, `Algorithm/` ... | 주제별 개념 정리 (개념 1개 = 파일 1개) |
| `Interview/` | 면접 대비 용어 정리 |
| `daily/` | 하루 메모 & 회고 (`YYYY-MM-DD.md`) |
| `templates/` | 작성용 템플릿 |

> 주제 폴더는 해당 주제의 첫 글을 쓸 때 만듭니다.

## ✍️ 작성 규칙

- 파일명: 영어 kebab-case (`async-await.md`, `rag-basics.md`)
- 커밋 메시지
  - `TIL: <주제> 정리` — 새 글
  - `Update: <주제> 내용 추가` — 기존 글 보완
  - `Interview: <용어> 추가` — 면접 용어
- 완벽하게보다 **매일** 쓰기
